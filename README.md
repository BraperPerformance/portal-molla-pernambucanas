# Portal Molla · Pernambucanas — Você de Casa Nova

Central do Cliente da campanha **Você de Casa Nova · Cartões Pernambucanas Elo**, produzida pela Agência Molla.

## Estrutura
- `index.html` — Central do Cliente (tela de login + hub de documentos)
- `diagnostico.html` — Diagnóstico e Plano da Campanha
- `funil_acessos.html` — Relatório de Funil de Acessos do Site (GA4)

## Publicação
Site estático — sem build e sem dependências. Todos os assets (logos e dados) estão embutidos nos próprios HTMLs.
Deploy automático via Vercel a cada push na branch `main`.
