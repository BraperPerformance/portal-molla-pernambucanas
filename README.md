# Portal Molla · Pernambucanas — Você de Casa Nova

Central do Cliente da campanha **Você de Casa Nova · Cartões Pernambucanas Elo**, produzida pela Agência Molla.

## Estrutura
- `index.html` — Central do Cliente (login + hub de documentos)
- `diagnostico.html` — Diagnóstico e Plano da Campanha
- `funil_acessos.html` — Funil de Acessos do Site (GA4)
- `report_disparo_wpp_segunda_onda.html` — Report do Disparo via WhatsApp (Segunda Onda)

## Publicação
Site estático, sem build e sem dependências. Deploy automático via Vercel a cada push na `main`.
